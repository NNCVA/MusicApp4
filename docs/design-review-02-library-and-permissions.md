# 媒体库与权限设计审阅 02

状态：已接受（2026-07-28）

## 已确认

- 媒体库以 MediaStore 全机音频为来源，路径规则负责包含或排除。
- 曲目仅接受 MP3、FLAC、WAV、AAC、M4A、OGG、OPUS，且时长大于 0；排除系统铃声、闹钟和通知音，保留录音、播客与有声书。
- 路径过滤提供“扫描全部”和“仅扫描指定目录”两个互斥模式；排除规则优先于包含规则。
- 曲目标识采用“存储卷名 + MediaStore ID”；删除后重新复制视为新曲目。
- 在首次授权、冷启动发现 MediaStore 版本变化、前台内容变更及用户手动刷新时同步，不设置周期性后台扫描。
- 列表扫描读取 MediaStore 元数据；播放、详情、封面和歌词按需解析内嵌标签。
- 批量操作包含加入播放列表、加入队列、下一首播放及隐藏曲目，不物理删除音频文件。
- 专辑以“存储卷 + MediaStore Album ID”分组；艺术家以 MediaStore Artist ID 分组，不拆分合作标签。
- 文件夹页按存储卷展示真实目录树；“播放全部”递归包含后代曲目。
- 各页面独立记忆排序；标题、艺术家、专辑默认升序，添加时间默认最新优先，时长默认最短优先。
- 播放列表名称长度为 `1–50` 个字符，忽略大小写禁止重名；删除集合不影响曲目文件。
- 当前版本仅发布 MediaSession 播放通知，不声明或请求 `POST_NOTIFICATIONS`；前台播放服务声明 `FOREGROUND_SERVICE` 与 `FOREGROUND_SERVICE_MEDIA_PLAYBACK`。
- 首次进入媒体库时先说明用途再请求音频读取权限；拒绝后不在每次启动重复请求，仍允许进入设置与关于页；永久拒绝时引导用户前往系统应用设置。
- 首次扫描且无缓存时展示全屏雷达动画；已有缓存后的自动或手动同步使用非阻塞顶部进度，不人为延长动画时间。
- 首次扫描与用户手动扫描完成后展示扫描结果对话框，包含曲目总数和可滚动的全部曲目列表；自动同步完成时不弹出。
- 单曲无权限、已删除或元数据损坏时跳过并继续扫描，结果对话框显示成功与跳过数量；MediaStore 整体查询失败时保留旧缓存并展示错误状态。
