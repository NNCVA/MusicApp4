# 导航栈、顶级入口与详情路由契约

> **状态：已接受（合并 ADR-0010，2026-09-11）**。

MusicApp 将侧边栏一级入口与二级详情页统一纳入明确的栈归属规则：点击任意 `TopLevelNavKey` 时重置目标栈为该入口的单元素根页面；从当前页面下钻到专辑、艺术家、歌单或文件夹详情时，始终压入当前一级入口的宿主栈，不切换栈，并对栈顶执行 Single-Top 去重。这样既避免跨入口带入旧详情，也保证详情间按返回键沿浏览路径逐级回退。

快照恢复要求栈底是对应一级入口根页面，后续元素只能是合法的二级详情路由；既有二进制编解码协议保持兼容。导航前进的时间节流与返回即时响应仍由 [ADR-0007](0007-use-layered-navigation-debounce.md) 独立负责，顶栏返回图标与窗口断点的语义由 [ADR-0018](0018-decouple-back-navigation-from-window-layout-policy.md) 独立负责。
