# 播放详情页响应式双栏布局

在设备处于横屏（视口宽度大于高度 `maxWidth > maxHeight`）或宽屏窗口时，全屏播放详情页（`PlayerSheet`）从单列纵向滑动画布切换为左右分栏布局。左侧固定居中呈现自适应缩放的黑胶旋转唱片（`RotatingArtworkDisc`，不附加歌词），保持旋转与切歌扩散动效的连续性；右侧使用 3 页 `HorizontalPager`（Page 0 播控、Page 1 同步歌词、Page 2 播放队列）承载多视图切换，用户通过自然横向滑动手势或辅助工具栏按钮在各视图间平滑过渡，不设置额外“返回播控”按钮；页面状态与竖屏 `FullPlayerPage` 保持完全双向映射，横竖屏旋转时不丢失当前浏览上下文；全屏背景下拉手势与系统返回键（`BackHandler`）统一支持平滑收起至底部迷你播放器。
