# 解耦主界面与播放界面主题模式

**Status**: accepted

## 背景

应用原先只有一个明暗主题模式。它包裹所有主界面内容，而播放详情页也只能被动使用同一套明暗外观；用户无法在保持主界面固定外观的同时，为全屏播放界面选择另一种明暗模式。

## 决策

1. 将现有主题模式定义为主界面主题模式，并新增独立的播放界面主题模式。两者都提供跟随系统、浅色和深色三态。
2. 播放界面主题模式只作用于展开后的全屏播放详情内容及其关联临时界面；迷你播放条、收起态播放器壳层和系统栏继续使用主界面主题。
3. 两个界面共享动态取色/预设主题选择；播放界面主题模式只决定明暗解析方式。播放界面的“跟随系统”直接读取 Android 系统明暗状态。
4. 旧版本用户首次读取设置时，将原主界面主题模式复制为播放界面初值；此后新增设置独立持久化。重置设置时两者均恢复为跟随系统。
5. 设置页将“外观”分组命名为“主界面”，将“Aero 背景”分组命名为“播放界面”，并在播放界面分组复用现有三态主题图标卡片。

## 结果

- 主界面和播放界面可以独立满足明暗偏好，且不需要维护第二套颜色调色板。
- 播放界面需要在自身内容树中应用独立主题；播放内容、封面背景和关联临时界面保持一致，迷你播放条仍与主界面连续。
- 旧设置数据无需改写既有主界面键；新增播放界面键缺失时执行一次迁移，避免升级后立即出现视觉突变。
- 系统栏不随播放界面切换，播放页视觉验收仍需覆盖系统栏对比度和展开/收起边界。
