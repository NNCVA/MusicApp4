# 垂直控制台均衡器布局、细轨圆环滑块与内置预设配置管理契约

## 背景与问题

在先前自定义均衡器实现中存在如下体验与架构局限：
1. **频段排版占用纵向高度过大**：原先各频段采用纵向单列平铺列表，每个频段占据一行独立的横向胶囊滑块（`BandSliderRow`），导致用户需要大幅向下滚动才能看到低音增强与环绕声控件，无法一览全局频响曲线。
2. **OEM 原生预设差异性大且缺失常见类型**：底层依赖 OEM 的 `Equalizer.getPresetName()`，不同厂商设备上预设数量、命名和曲线极不一致，且普遍缺少用户最常用的“低音增强 (Bass Boost)”与“人声增强 (Vocal)”等调音预设。
3. **滑块样式与专业调音心智不匹配**：使用了与常规系统设置相同的粗体 `InsetPillSlider`（内嵌胶囊滑块），缺少专业调音台中“细轨 + 镂空圆环”的细腻微调手感与 0dB 基准线可视化。
4. **低音增强与环绕声控制冗余**：先前低音增强与环绕声各自维护独立的 `Switch` 开关与 `0..1000` 百分比滑块，存在“开了开关但值为0”或“关了开关无法滑动”的割裂交互。

## 决策

### 1. 顶栏操作整合与预设选择交互
- **顶部操作栏**：在页面 `CategoryHeader` 下方采用单张通栏卡片，左侧放置预设下拉选择菜单（展示当前预设名称及下拉指示箭头，如“低音 ▾”），右侧放置均衡器总开关（Switch）。
- **微调联动行为**：用户选择任一预设后，手动拖动任意物理频段滑块，系统立即自动将预设状态切换为“自定义 (Custom)”；切换预设时，各频段增益平滑更新为对应预设配置。

### 2. 集中化内置预设注册表（Built-in Preset Registry）
- 在应用层建立统一的 `BuiltInEqualizerPresets` 配置注册表，标准化 5 频段（60Hz、230Hz、910Hz、3.6kHz、14kHz）的增益曲线（以网络与专业调音标准为基准，限制在 -10.0dB ~ +10.0dB）：
  - **平直 (Flat)**: [0, 0, 0, 0, 0] dB
  - **低音增强 (Bass Boost)**: [+4.0, +2.0, -1.0, -2.0, 0.0] dB
  - **人声增强 (Vocal)**: [-1.0, 0.0, +2.5, +3.0, +1.0] dB
  - **摇滚 (Rock)**: [+3.0, 0.0, -1.0, +2.0, +3.0] dB
  - **流行 (Pop)**: [+2.0, +1.0, 0.0, +2.0, +2.0] dB
  - **电子 (Electronic/Dance)**: [+4.5, 0.0, -1.0, +2.0, +3.5] dB
  - **爵士 (Jazz)**: [+1.0, +2.0, 0.0, +1.5, +2.0] dB
  - **古典 (Classical)**: [+1.5, 0.0, 0.0, +0.5, +2.0] dB
  - **民谣 (Folk)**: [+1.5, +1.0, 0.0, +1.0, -0.5] dB
  - **自定义 (Custom)**: 用户自由调整
- 彻底屏蔽 OEM 硬件预设的不确定性，确保跨设备听感一致性与可预测性。

### 3. 垂直频段调音台（Vertical Multi-band Equalizer Console）
- **坐标系布局**：
  - **横轴**：各物理频段中心频率（从低频到高频：60Hz、230Hz、910Hz、3.6kHz、14kHz），固定渲染在各垂直轨道底部；
  - **纵轴**：增益分贝大小，范围锁定为 `[-10.0 dB, +10.0 dB]`；左侧提供 `+10dB`、`+5dB`、`0dB`、`-5dB`、`-10dB` 刻度标签与极细水平参考线，中心 `0dB` 线作为高亮基准线；
  - **实时读数**：各频段垂直轨道的正上方实时显示当前分贝值（例如 `+3.2 dB`）。
- **细轨圆环滑块规范**：
  - **轨道**：2.5dp 细线轨道；以 `0dB` 基准线为中心向滑块当前位置双向延伸高亮色（正增益向上填充、负增益向下填充）；
  - **圆环**：外径 18dp、环宽 2dp 的镂空细圆环（Thumb）；外围包裹满足无障碍要求的 48dp 透明触控热区；按下拖拽时提供平滑弹性放大动效（22dp）与触觉/视觉即时响应。

### 4. 一体化音效增益滑块（低音增强与环绕声）
- **去掉独立 Switch 开关**：低音增强与环绕声均采用一体化细轨圆环滑块，调节范围为 `0.0 dB ~ 10.0 dB`。
- **底层状态映射**：
  - 当数值处于 `0.0 dB` 时，底层对应的 `BassBoost` 或 `Virtualizer` 自动设为 `enabled = false`，强度为 0；
  - 当数值 `> 0.0 dB` 时，底层自动设为 `enabled = true`，并将 `0.0 .. 10.0 dB` 线性换算为底层 `0 .. 1000` 强度参数（1.0 dB = 100 强度）。

## 影响与验证

- **向后兼容**：持久化设置中存储的 `bandLevels` 与 `bassBoostStrength` 自动与新范围对齐；单向数据流与 `AudioEffectController` 无缝衔接。
- **验证计划**：
  - 单测：验证内置预设数据注册表、各预设增益数值与 -10dB ~ +10dB 边界、微调频段自动切换为自定义、0-10dB 强度换算与启用逻辑；
  - Compose UI 仪器测试：验证垂直滑块全热区拖拽手势、下拉预设菜单切换与无障碍语义树合并。
