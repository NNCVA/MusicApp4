# 中等与展开窗口统一使用分组卡片侧栏

> **状态：已接受（带修订附注）(Accepted with Amended Notes)**。
>
> **修订附注（2026-09）**：
> 侧栏卡片分组与紧凑窗口（`<600 dp`）50% 推移式侧栏契约保持有效。中等窗口（`600–839 dp`）与展开窗口（`≥840 dp`）的常驻侧边栏宽度已由原定的 `240 dp` / `256 dp` 统一收敛升级为 `300 dp`（见 `DesignTokens.kt:21-22`），以保证双语标签展示完整度与平板横屏下的排版舒适感。

MusicApp 在 `<600 dp` 使用窗口宽度 `50%` 的推移式侧栏，展开时主内容等距右移并由窗口边界裁切；在 `600–839 dp` 使用宽度 `240 dp` 的常驻侧栏，在 `≥840 dp` 使用宽度 `256 dp` 的常驻侧栏。三档窗口统一采用“顶部快捷操作、媒体浏览入口、应用操作入口”三组圆角卡片；该方案以跨窗口视觉和入口一致性为优先，接受中等窗口比 Navigation Rail 占用更多横向空间的代价，并通过较窄的 `240 dp` 中等侧栏保留主内容宽度。
