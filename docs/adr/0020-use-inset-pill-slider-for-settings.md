# 普通设置统一使用内嵌胶囊滑块

**Status**: accepted

淡入淡出时长、睡眠定时、歌词字号和歌词字重等普通数值设置统一使用共享的 `InsetPillSlider`：活动值与未活动值共用胶囊轨道，16dp 白色 Thumb 保持在 16dp 轨道内部，同时保留原有范围、步进、回调时机和 Material Slider 的无障碍语义。设置页淡入淡出时长在拖动与点击过程中都按 250 毫秒最小单位吸附，文案即时显示 draft，松手时沿用现有 ViewModel 路径提交一次；紧凑布局的抽屉手势在子控件消费横向拖动后让出控制权，空白区域仍保留抽屉滑入。播放详情页的 `InteractiveThinProgressBar` 继续保持细长交互进度条，因为它拥有独立的 pending seek 与单次提交契约，不属于普通设置滑块。
