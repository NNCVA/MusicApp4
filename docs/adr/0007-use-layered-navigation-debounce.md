# 使用分层导航防抖与 Single-Top 幂等策略

针对页面切换与列表项连击产生的重复压栈、转场动画并发冲突等问题，MusicApp 采用分层防御策略：
1. **状态层 Single-Top 幂等**：`Navigator` 在处理详情页压栈时比对当前栈顶，若栈顶已是目标路由则忽略本次压栈，确保底层状态机天然幂等并具备确定性单测验证能力；
2. **导航入口时间节流**：`MainNavigation` 在 `commitNavigation` 前进跳转时引入 `300 ms` 时间窗口节流，对齐 Compose 页面水平平移转场动效时长，拦截多指并发与高频连击；
3. **返回导航即时响应**：返回操作（`handleBack` / `popCurrent`）不参与前进节流，保持用户连续回退时的即时交互响应。

选择分层策略是为了在不侵入各个具体 Screen UI 组件的前提下，兼顾底层状态一致性与界面转场稳定性；代价是导航调度层需记录前进步长的时间戳。
