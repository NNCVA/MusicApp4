# 统一实体图片的透明加载态与终态回退

**Status**: accepted

所有非播放器的实体图片（曲目、专辑、艺术家和歌单）统一经历“透明加载 → 真实图片”或“终态回退”三态：请求进行中保留容器几何但不初始化降级图，成功后立即显示真实图片，确认无图或不可恢复失败时才显示 `ic_playlist_album`。已知没有图片请求的实体直接进入终态回退；图片层不再绘制会遮住后方内容的独立背景，调用方仍保留自身的尺寸、裁剪、圆角和无障碍语义。播放器全屏动态封面与 Aero 背景继续使用独立规则，不受本决定约束。

## Consequences

- 图片加载策略由共享实体图片组件集中维护，避免各列表逐处设置 placeholder/error 造成行为漂移。
- 同一列表槽位切换到新实体时，旧图片在新请求完成前不保留，避免图片与文字错配。
- 本地 JVM、Lint 和 Debug APK 门禁可以验证状态契约与迁移完整性；真实设备视觉仍需单独验收。
