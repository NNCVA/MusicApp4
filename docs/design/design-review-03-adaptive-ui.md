# 自适应界面设计审阅 03

状态：已接受（2026-07-28）

## 已实现基线

- 已建立八个可序列化一级 Route Key、五个详情 Route Key、独立返回栈快照与版本化恢复编码；切栈、重复点击回根、媒体浏览根页动态锚定及返回桌面语义已接入 Navigation 3。
- 已建立 `<600 dp` 半宽推移式三组卡片、`600–839 dp` 的 `240 dp` 常驻三组卡片、`≥840 dp` 的 `256 dp` 常驻三组卡片，以及导航与业务内容之上的应用级 Player Sheet；Mini/Full 双锚点、三子页、返回折叠与展开时抽屉手势禁用已接入，具体屏幕负责一次性消费 Insets。
- 已接入专辑的 `160 dp` 最小单元自适应网格、播放列表与艺术家集合页单列行、文件夹单列目录树以及所有三类全屏详情页；媒体详情保持独立全屏 Route，不引入会压缩播放内容的多窗格。

## 侧边栏改造（已实现，2026-07-30）

- 整高模态面板、纯文字入口、大面积胶囊选中状态及中等窗口 Navigation Rail 已改为三组 Material 3 圆角卡片；背景图片、背景颜色和 Aero 效果未修改。
- 顶部快捷操作为退出、明暗模式和均衡器占位；媒体浏览组为单曲、专辑、艺术家、文件夹、播放列表；应用操作组为扫描音乐、播放历史、设置、关于。
- 八个一级 Route Key 保持不变；侧边栏 Scan row 后续进入独立扫描页面，Tracks 页面不承载扫描交互，不新增“音乐库”或“统计”路由。
- 导航项使用彩色图标，当前页通过 Tab 选中语义与清爽视觉呈现，不使用整行胶囊底色或额外侧边条。
- 退出按钮显示“完全退出、回到桌面、取消”三项选择；完全退出保存快照、停止服务并移除任务，回到桌面保留播放与通知。
- 明暗模式按“跟随系统、浅色、深色”循环；均衡器只显示后续版本提示。

## 已确认

- 首版适配手机、平板、折叠屏及 ChromeOS 可缩放窗口。
- 首版不制作 TV、Android Auto 或 XR 专用界面，但保留系统 MediaSession 控制能力。
- 窗口宽度 `<600 dp` 使用推移式侧栏，`600–839 dp` 使用宽度 `240 dp` 的常驻侧栏，`≥840 dp` 使用宽度 `256 dp` 的常驻侧栏；三档窗口均使用相同的三组卡片，尺寸变化时保留当前页面与返回栈。
- 八个一级入口分别维护可保存返回栈；重复选择当前入口返回该入口根页；单曲、专辑、艺术家、文件夹、播放列表中的最近选择项作为当前媒体浏览根页，应用操作页返回该根页，扫描页面返回进入前页面，在该根页返回时将任务移至后台并回到桌面。
- 手机推移式侧栏宽度为当前窗口的 `50%`，展开时主内容等距右移并裁切，其可见区域使用 `18%` 黑色遮罩并支持点击关闭；中等和展开窗口的常驻侧栏分别固定为 `240 dp` 和 `256 dp`。
- 播放器使用位于业务导航之上的应用级 Player Sheet：同一容器内重叠放置 Mini 与 Full 两层，折叠锚点固定露出 `80 dp` Mini，并由应用壳层为所有业务内容统一保留同高的底部空间；展开锚点铺满可用窗口，禁止进入隐藏态。
- 侧栏打开时 Mini 保持完整窗口宽度，覆盖在侧栏与主内容之上并继续响应操作；侧栏滚动区域为 Mini 预留 `80 dp`。
- 点击 Mini 直接展开；纵向拖动时 Sheet 跟手移动，Mini 在滑动进度 `0%–25%` 淡出，Full 在 `25%–100%` 淡入；不做封面连续缩放、共享元素形变或第三个半展开锚点。
- 返回、全屏顶部下拉按钮或向下拖动将 Player Sheet 折叠并露出原业务页面，不压入或弹出 Navigation 3 返回栈；展开及拖动期间禁用抽屉侧滑手势。
- 全屏播放器页面顺序为“封面／歌词／队列”；首次打开显示封面，本次进程内恢复上次页面，切歌不重置，进程重启后回到封面。
- 手势优先级为歌词或队列纵向滚动、子页横向翻页、Player Sheet 纵向折叠；列表到顶部后继续下拉时移交 Player Sheet，列表底部继续上拉只做阻尼回弹。
- Mini 封面在紧凑窗口使用 `16 dp` 圆角，中等与展开窗口使用 `20 dp` 圆角；队列页标题区与主控制区共享同一播放模式状态。
- Aero 背景、封面和列表可绘制到系统栏后方；按钮、文字与首尾列表项按安全区避让，系统栏图标明暗跟随主题。
- 单曲、历史、文件夹、队列、播放列表及艺术家集合页保持单列；设置与关于内容最大宽度为 `720 dp` 并居中。
- 专辑使用最小卡片宽度 `160 dp` 的自适应网格。
- 艺术家集合页固定按名称升序，不提供集合页排序；右侧完整 `0/A–Z/#` 索引支持点击和沿索引拖动定位，空标签只承担定位语义；艺术家详情页沿用详情页排序。
- 艺术家集合行显示圆形头像、艺术家名称和短曲目数；头像按曲目的 `TrackId` 稳定升序选择首张可用内嵌封面，没有可用封面时使用艺术家占位图。
- 使用稳定的 `MusicDimensions`、`MusicShapes`、`MusicTypography` 主题令牌按紧凑、中等、展开窗口提供统一视觉规格；页面不直接写圆角、间距或字号，不升级实验版 Compose Styles API。
- 艺术家集合行名称单行省略并显示短曲目数，其他标题最多两行；卡片和列表项使用设计令牌规定的固定高度，不随文字内容增高。
- Full Player 与艺术家集合头像使用圆形封面，其他封面统一使用圆角矩形。
- 完整尊重系统字体缩放且不限制 `fontScale`；文字超出固定组件高度时按既定行数省略。
- 歌曲类列表项与迷你播放器使用相同的 `80 dp` 固定高度。
- 专辑网格卡片使用正方形封面加 `64 dp` 固定信息区；封面及卡片圆角在紧凑窗口为 `16 dp`，中等及展开窗口为 `20 dp`。
- 紧凑、中等、展开窗口的页面水平边距分别为 `16/24/32 dp`，卡片间距分别为 `12/16/20 dp`；组件内部尺寸遵循 `4 dp` 基准网格。
- 曲目标题与艺术家字号相差 `4 sp`：紧凑窗口分别为 `16/20 sp` 与 `12/16 sp`，中等及展开窗口分别为 `18/22 sp` 与 `14/18 sp`；标题使用 `onSurface`，艺术家使用 `onSurfaceVariant`，不通过透明度弱化颜色。
- 颜色来源可选 Material You 动态取色或预设主题，明暗模式独立提供跟随系统、浅色、深色；Android 12 以下的动态取色回退默认预设，切换时不重建 Activity。
