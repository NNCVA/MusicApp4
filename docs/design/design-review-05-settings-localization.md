# 设置与本地化设计审阅 05

状态：已接受（2026-07-28）

## 已实现基线

- Preferences DataStore 已通过 `StateFlow` 提供七类设置、逐项更新与默认值重置；路径规则未进入 DataStore。
- 读取 `IOException` 时回退默认设置，其他异常继续上抛；Auto Backup 仅白名单包含 `files/datastore/`，数据库不进入备份。
- English 与简体中文资源已建立自动键一致性检查，后续新增 `string`/`plurals` 必须同步提供。
- 设置页已组装主题、明暗、语言、Aero、淡出淡入、扫描模式与 Room 路径规则；路径变更可取消立即重扫并持久化待同步 revision，只有该 revision 确认发起的成功完整扫描可清除。
- 主题、明暗与 Aero 由根 Compose 树响应式消费；应用语言通过 `AppCompatDelegate.setApplicationLocales` 统一切换，AGP 从资源配置自动生成 LocaleConfig。
- 重置配置、清空历史、删除全部播放列表和重建媒体库缓存均已接入独立确认与作用域测试；重置不清除 Room 业务数据。

## 已确认基础

- 应用语言提供“跟随系统／简体中文／English”。
- 启用 AGP 自动生成 `LocaleConfig`，使用 `AppCompatDelegate.setApplicationLocales` 同步 Android 13+ 系统应用语言设置。
- 语言切换允许 Activity 重建，但必须恢复导航、播放与滚动状态。

## 已确认推荐

1. **字符串资源契约**：默认 `values/strings.xml` 使用 English，`values-zh-rCN/strings.xml` 提供简体中文；所有用户可见文本、无障碍说明和通知文案均来自资源，缺失翻译由 Lint 阻止发布构建。
2. **本地化格式**：数量使用 `plurals`，日期、数字与文件大小按当前应用语言格式化，播放时长统一为本地化的 `mm:ss` 或 `h:mm:ss`；禁止拼接可见句子。
3. **设置持久化**：使用单一 Preferences DataStore 保存带类型的设置状态，由 Repository 暴露 `StateFlow`；界面只调用设置意图，不直接读写键名。
4. **初始默认值**：颜色来源在 Android 12+ 为动态取色、低版本为默认蓝；明暗与语言跟随系统，Aero 默认光晕气场，淡出淡入默认 `500 ms`，DataStore 中的扫描模式默认“扫描全部”；包含与排除目录作为路径规则保存在 Room，初始均为空。
5. **设置生效时机**：主题、明暗、Aero 与语言选择立即生效；淡出淡入时长从下一次切歌生效；正在执行的扫描使用启动时规则，不在中途改变。
6. **路径规则变更**：保存包含或排除目录后立即提示重新扫描；用户确认后执行手动扫描并展示扫描结果对话框，取消则保留新规则并标记媒体库待同步。
7. **重置应用配置**：仅将 DataStore 设置恢复默认值，扫描模式恢复“扫描全部”；不删除 Room 中暂时不生效的路径规则，也不删除播放列表、历史、媒体库缓存或物理音频，确认对话框明确列出保留数据。
8. **数据管理入口**：清空播放历史、删除全部播放列表、重建媒体库缓存分别提供独立操作与确认；重建缓存不会删除播放列表本身，已挂载卷成功完整同步确认的缺失曲目及其关联直接移除。
9. **备份边界**：Auto Backup 只包含用户设置；排除媒体库缓存、队列、历史和播放列表数据库，避免将依赖设备 MediaStore ID 的数据恢复到另一台设备。
10. **关于与隐私**：版本信息从安装包读取，开发者与致谢来自资源，开源许可由构建生成并离线展示；首版不声明 `INTERNET` 权限，不接入统计、崩溃上传或任何音频数据上传。
