# 首版最终未决盘问 11

状态：已接受（2026-07-28）

1. **平台基线**：正式支持 `minSdk 26`、`targetSdk 37`，不为 API 25 及以下提供兼容。
2. **互斥播放模式**：列表循环、单曲循环、随机播放三种模式互斥，首次启动默认列表循环，不提供循环关闭状态，也不组合随机与循环。
3. **手动切歌与队尾**：手动“上一首／下一首”始终尝试切换当前播放顺序中的相邻项，单曲循环只影响自然结束；列表循环在队尾回到队首继续播放。
4. **随机序列**：进入随机播放时同时保存原始队列并生成、持久化一份稳定随机顺序，当前曲目保持不变；一轮结束后重新生成下一轮并继续播放，且两轮边界不连续重复同一曲目；切换到列表循环或单曲循环时恢复原始顺序并保留当前曲目。
