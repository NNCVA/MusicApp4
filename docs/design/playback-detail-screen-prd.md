# 播放详情页专辑视图 PRD

## 1. 文档概述

### 1.1 背景与设计演进

当前应用中的播放详情页由 `PlayerSheet` 承载，展开后使用顶部“收起 / 歌曲名 / 歌曲信息”、横向分页（封面、歌词、队列）、圆形封面、中间重复歌曲名/艺术家名、粗粒度 Material3 `Slider` 进度条、±10 秒微调按钮以及孤立的循环按钮。参考图 2 记录了当前的实际实现。

参考图 1 确立了新的现代极简视觉与操作层级：
- **顶部信息区**：聚焦于曲目元数据，左上角左对齐展示歌曲名（超长时启用平滑跑马灯效果）和艺术家名，移除顶部多余的文本操作按钮，全页通过手势下滑或系统返回键收起。
- **中部唱片区**：居中突出展示大尺寸圆形专辑封面，保持黑胶唱片质感与优雅旋转动效；移除封面下方重复的歌曲名与艺术家名；暂不增加封面下方的小歌词预览。
- **细长进度条**：由粗重的标准 Slider 改为极简纤细的播放进度条，平时保持细线质感，拖动时提供多维交互反馈（线条动态加粗、高亮指示、浮动时间气泡与触觉震动反馈）。
- **核心主控区**：聚焦为“上一首 / 播放或暂停 / 下一首”三核心按键，移除冗余的 ±10 秒快进快退，操作层级更清晰、触控面积更大。
- **底部辅助工具栏**：在主控区下方统一收纳 5 个辅助功能入口：循环模式（已有三循环）、睡眠定时（新增秒表图标，当前版本入口占位）、音效/均衡器（复用已有波形图标，当前版本入口占位）、播放队列（已有列表图标）、歌曲信息（新增横向三个点图标）。

### 1.2 目标

- **信息降噪与层次重塑**：消除页面内歌曲名与艺术家名重复展示的问题，突出顶部元数据与中部圆形唱片封面。
- **细长交互进度条与动效反馈**：打造精致细长进度条，在保持系统级 48dp 触控热区的同时，支持拖动时的视觉（动态变宽/指示点/时间气泡）与触觉反馈，并在松手时精准 seek。
- **主控收敛**：将核心播控收敛为上一首、播放/暂停、下一首三键。
- **辅助工具栏集成**：按“循环、睡眠定时、音效/均衡器、队列、歌曲信息”横向排布，提供统一的触控热区与无障碍播报。
- **无缝架构延续**：完整继承现有 `PlayerUiState`、`PlaybackControllerFacade`、`AeroBackground`、双语国际化与手势路由体系。

### 1.3 非目标

- 本版本不实现睡眠定时的定时停止播放业务逻辑（仅提供入口及“功能开发中”交互反馈）。
- 本版本不实现音频均衡器与音效调节引擎业务逻辑（仅提供入口及“功能开发中”交互反馈）。
- 本版本暂不添加封面下方的 3 行小歌词实时预览（封面下方空间自适应留白；完整歌词页由分页或独立入口承载）。
- 本版本不改变既有播放模式模型（列表循环、单曲循环、随机播放）及队列管理底层数据结构。

## 2. 领域词汇对齐

- **播放详情页 (`PlayerSheet`)**：从底部可向上展开的全屏沉浸式播放界面；本文档专门规范其默认的专辑视图 (`ARTWORK`)。
- **跑马灯标题 (`Marquee Title`)**：当歌曲名称长度超出单行可用宽度时，以平滑匀速横向滚动的动效展示完整标题；未超长时保持居左静态。
- **圆形专辑唱片 (`Artwork Disc`)**：当前播放曲目的圆形封面展示组件，具备播放中匀速慢转、切歌快速回正与径向波纹扩散转场动效。
- **细长播放进度条 (`Thin Interactive Progress Bar`)**：静态播放时呈现为精致细线（2dp~3dp）但具备不小于 48dp 隐形触控热区的进度控制组件；支持点击定位与按压拖动。
- **拖动反馈效果 (`Drag Feedback Effect`)**：在用户触控拖动进度条过程中，通过进度条动态加粗、高亮触控指示点、手指上方浮动时间标签及触觉微震动向用户传递的连续交互状态。
- **核心主控区 (`Core Playback Controls`)**：位于进度条下方的核心播放动作集合，仅包含上一首、播放/暂停、下一首三项操作。
- **辅助工具栏 (`Secondary Toolbar`)**：横向排布在主控区下方的五个功能入口：循环模式、睡眠定时、音效/均衡器、播放队列、歌曲信息。

## 4. 界面布局与组件规范

### 4.1 页面骨架结构

```text
┌────────────────────────────────────────────────────────┐
│  [歌曲名称] (超长时平滑横向跑马灯滚动)                   │
│  [艺术家名称]                                           │
│                                                        │
│                                                        │
│                    ╭───────────╮                       │
│                    │   圆形    │                       │
│                    │ 专辑唱片  │                       │
│                    ╰───────────╯                       │
│                                                        │
│                                                        │
│  ──────●─────────────────────────────────────────────  │ (细长进度条: 拖动反馈)
│  01:50                                           03:28 │
│                                                        │
│             ⏮          ▶ / ⏸          ⏭             │ (三键核心主控)

└────────────────────────────────────────────────────────┘
```

### 4.2 顶部信息区规范

1. **排列结构**：
   - 采用 `Column` 垂直堆叠，位于安全区下方，靠左对齐，左侧水平内边距使用 `MusicTheme.dimensions.topBarHorizontalPadding`。
   - 彻底移除原顶部栏的“收起”与“歌曲信息”文字按钮。
2. **歌曲标题**：
   - 字号与样式：采用 `MusicTheme.typography.titleLarge`（或 `headlineSmall`），字重加粗，主色为 `MusicTheme.colors.onSurface`。
   - 跑马灯机制：通过 Compose 官方修饰符 `Modifier.basicMarquee(iterations = Int.MAX_VALUE)` 实现。当标题文本宽度超出可用区域时，自动平滑横向滚动，并在循环间提供适当间距；当文本未溢出时，保持居左静止。
   - 切歌重置：当曲目发生变化时，跑马灯自动重置回到起始位置。
3. **艺术家名称**：
   - 位于标题下方，间距 4dp。
   - 文本样式：`MusicTheme.typography.bodyMedium`，颜色为 `MusicTheme.colors.onSurfaceVariant`。
   - 多艺术家处理：按照多艺人规范显示（如 `Arc North / Krista Marina`），超长时使用尾部省略号截断（`TextOverflow.Ellipsis`），并在语义树中保留完整文本。
4. **收起手势机制**：
   - 播放详情页依托全屏下滑手势与系统返回手势（BackHandler）完成平滑收起，无需占用顶部宝贵的视觉空间。

### 4.3 中部专辑唱片区规范

1. **唱片组件**：
   - 居中展示 `RotatingArtworkDisc`，使用当前曲目的封面资源。
   - 唱片尺寸：基于窗口尺寸自适应（Compact 竖屏推荐直径 260dp~280dp），垂直方向居中弹性自适应（`weight(1f)`），确保在不同屏幕高度下均不会遮挡底部控制区。
2. **动效规范**：
   - 播放时保持 20 秒/圈的匀速顺时针平缓旋转；
   - 暂停时原位静止；切歌时 350ms 逆时针平滑回正，新封面以中心向外径向扩散展开。
3. **文字移除**：
   - 彻底移除图 2 中位于唱片正下方的二次歌曲名和艺术家名文本块，彻底消除信息冗余。

### 4.4 细长播放进度条规范

1. **几何形态与触控尺寸**：
   - **视觉厚度**：默认静态播放状态下，进度轨道高度为 2.5dp~3dp，转角为圆形圆角。
   - **触控热区**：整个进度条容器垂直高度保证为 `MusicTheme.dimensions.minimumTouchTarget`（48dp），用户在任意位置轻触或划动均能灵敏捕获手势。
2. **颜色规范**：
   - 已播放部分（Active Track）：采用高对比度强调色（如 `MusicTheme.colors.primary` 或深色主题下的高亮轨道色）。
   - 未播放部分（Inactive Track）：采用低饱和度半透明轨道底色（如 `MusicTheme.colors.surfaceVariant.copy(alpha = 0.4f)`）。
3. **拖动交互与多维反馈效果**：
   - **按下态 (Pressed)**：用户手指触碰进度轨道时，视觉轨道厚度平滑放大至 5dp~6dp，并在当前触控位置浮现高亮圆点滑块（Thumb）；
   - **拖动中 (Dragging)**：
     - 手指横向移动时，已播放轨道与滑块跟随手指实时移动；
     - 触发轻量级触感反馈（`HapticFeedbackType` 触发微震）；
     - 可在滑块上方或时间栏中高亮呈现拖拽中的目标时间预览，避免用户在松手前盲目猜测位置；
   - **松手态 (Released)**：
     - 用户抬手时，轨道平滑缩回 2.5dp~3dp 细线状态，滑块淡出隐去；
     - 正式触发 `onSeek(fraction)` 将播放位置提交到底层控制器；
     - 避免在快速拖拽过程中频繁触发解码器连续 seek 导致音频爆音或卡顿。
4. **时间指示文本**：
   - 位于进度条正下方两侧，左侧为当前进度（如 `01:50`），右侧为音频总时长（如 `03:28`）。
   - 文本样式：`MusicTheme.typography.labelSmall`，字体采用等宽数字特性（FontFeatureSettings: "tnum"），防止时间跳动时产生横向抖动。

### 4.5 核心主控区规范

1. **三键极简布局**：
   - 顺序固定为：**上一首 (`⏮`)** -> **播放/暂停 (`▶` / `⏸`)** -> **下一首 (`⏭`)**。
   - 彻底移除 ±10 秒快退与快进按钮。
2. **按键视觉与热区**：
   - 三个按键水平等间距分布或居中大间距排布（如水平间距 32dp~48dp）。
   - 播放/暂停按钮居中，尺寸最醒目（图标尺寸 36dp~40dp，触控热区不小于 56dp）；播放状态显示暂停图标，暂停/停止状态显示播放图标。
   - 上一首与下一首图标尺寸 28dp~32dp，触控热区 48dp。
   - 禁用态遵从播放队列状态（`canSkipPrevious` / `canSkipNext`），禁用时透明度降为 38%。

### 4.6 底部辅助工具栏规范

1. **五项入口排布**：
   - 从左到右依次为：
     1. **循环模式 (`PlaybackMode`)**：复用三循环图标（列表循环 `ic_playback_repeat`、单曲循环 `ic_playback_repeat_one`、随机播放 `ic_playback_shuffle`）。点击在三种模式间循环切换。
     2. **睡眠定时 (`Sleep Timer`)**：新增秒表图标（`ic_playback_sleep_timer`）。当前版本作为功能入口占位，点击触发“功能开发中”反馈提示。
     3. **音效/均衡器 (`Equalizer`)**：复用波形图标（`ic_sidebar_equalizer`）。当前版本作为功能入口占位，点击触发“功能开发中”反馈提示。
     4. **播放队列 (`Queue`)**：复用列表图标（`ic_common_view_list`）。点击切换打开播放队列面板。
     5. **歌曲信息 (`Track Info`)**：新增横向三点图标（`ic_common_more_horizontal`）。点击打开全量音频元数据对话框（`TrackInfoViewer`），完美替代旧版顶部“歌曲信息”文字。
2. **尺寸与无障碍**：
   - 辅助栏每个图标采用 `BareIconButton`，尺寸均为 48dp × 48dp（满足最小触控热区）。
   - 每个入口必须通过 `stringResource` 提供对应的中文与英文 Content Description。

## 5. 数据流与交互状态

### 5.1 架构与单向数据流约束

- **纯响应式 Composable**：`PlayerSheet` 仅观察 `PlayerUiState`，用户的所有交互（点击、拖拽、切歌、切换模式）均作为事件提交给 `PlayerViewModel` / `PlaybackControllerFacade`。
- **拖拽隔离保护**：拖动进度条过程中，本地记录正在拖拽的 `isDragging` 标志与 `dragFraction`，避免底层高频刷新的 `positionMs` 覆盖用户的手指触控位置；松手时提交一次 seek 并解除拖拽标志。
- **Room 与播放服务解耦**：页面内不得直接与 Room、DataStore 或底层 ExoPlayer 通信。

### 5.2 边界与异常状态处理

- **无当前曲目**：自动折叠收起 `PlayerSheet`。
- **未知音频时长 (duration <= 0)**：进度条处于初始 0 位置并禁用拖拽，时间文本显示 `--:--`。
- **极窄屏幕适配 (Compact Narrow)**：辅助工具栏在窄屏下采用自适应均分宽度（`Arrangement.SpaceAround`），避免图标挤压或超出屏幕边缘。
- **长标题/多艺人极端文本**：标题通过跑马灯完整展现，艺术家名尾部截断并保留全量无障碍语义，确保排版高度固定稳定，不发生跳动。

## 6. 验收标准

### 6.1 视觉验收
1. 顶部左对齐呈现歌曲标题与艺术家，标题超长时跑马灯匀速滚动，无“收起”或“歌曲信息”顶部文字。
2. 中部为居中大尺寸圆形唱片，切歌回正与展开动效流畅，下方无冗余重复歌曲名。
3. 进度条呈现为精致细线，时间数字位于进度线正下方两侧且不抖动。
4. 主控区呈现上一首、播放/暂停、下一首三键，无 ±10 秒按钮。
5. 底部呈现 5 个小图标按钮（循环、睡眠定时、音效、队列、歌曲信息）。
6. 背景为封面自适应柔和弥散渐变。

### 6.2 交互与行为验收
1. **进度条拖动**：按下时细线平滑加粗并显示指示滑块，手指滑动时进度与时间实时响应并伴随微震反馈；松手后音频精准跳转且进度线恢复细线。
2. **模式循环**：点击循环图标可在列表循环、单曲循环、随机播放之间无缝切换，图标实时更新。
3. **占位入口提示**：点击睡眠定时或音效均衡器图标，优雅弹出“功能开发中，敬请期待”浮动提示气泡，不发生崩溃或伪造操作。
4. **队列与详情**：点击队列图标切换至队列页面；点击横向三点图标弹出歌曲元数据对话框。
5. **手势收起**：在页面背景下拉或按系统返回键平滑收起播放页。

### 6.3 自动化测试与工程质量
- JVM 单元测试覆盖：进度拖拽状态计算、跑马灯触发条件、播放模式切换、占位状态事件映射。
- Lint 门禁与无硬编码文案检查：所有图标具备无障碍标签，中英双语资源补齐。
