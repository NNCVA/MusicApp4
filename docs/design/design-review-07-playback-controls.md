# 播放控制设计审阅 07

状态：已接受（2026-07-28）

1. **播放启动反馈**：用户点击曲目后立即更新当前曲目信息并进入准备状态；准备超过 `300 ms` 才显示缓冲指示，避免本地文件快速启动时闪烁，播放失败则恢复可操作状态。
2. **快进快退**：每次快退或快进 `10 秒`，结果限制在 `0..duration`；不支持长按连续触发，锁屏、蓝牙与通知仍遵循外部控制器发送的命令。
3. **上一首语义**：无论当前曲目已播放多久，点击“上一首”都直接尝试切换到当前播放顺序的上一首，不先回到本曲开头；位于队首时，列表循环跳到队尾，单曲循环保持队首，随机播放按当前稳定随机序列处理，手动上一首不受单曲循环限制。
4. **坏文件处理**：单曲准备或解码失败时标记本次播放不可用、显示曲名与简短原因并自动尝试下一首；淡出完成后目标曲目解码失败时保持静音，按当前模式寻找下一首可播放曲目，找到后再淡入；连续失败遍历一轮仍无可播放曲目时停止并恢复正常音量状态，禁止无限循环重试。
5. **播放快照**：原始队列、曲目、位置、播放模式、随机模式的稳定序列及当前播放实例的计时状态在队列变化、切歌、Seek、暂停及服务销毁时写入 Room；播放中每 `5 秒` 更新位置与实例计时，已播至结尾的曲目恢复时按当前模式选择下一首。退出随机播放时恢复原始队列顺序并保留当前曲目。
6. **随机模式加入队列**：普通“加入队列”将新增曲目追加到原始队列末尾，并随机插入当前稳定随机序列的未播放区间；已经播放的前缀和当前曲目保持不变。
7. **随机模式下一首播放**：“下一首播放”将所选曲目按选择顺序插入当前稳定随机序列的当前项之后，并追加到原始队列末尾；当前曲目结束后立即播放这些曲目。
8. **移除当前曲目**：从队列移除当前曲目时，同时从原始队列和稳定随机序列删除，并立即播放当前模式下的下一首；队列只剩该曲目时停止播放并清空当前曲目。
