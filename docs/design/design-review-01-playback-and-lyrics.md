# 播放与歌词设计审阅 01

状态：已接受（2026-07-28）

以下十项是基于当前需求与 Media3 行为确认的实现约束。

1. **淡出淡入触发范围**：自动切到下一首、手动上一首和下一首均执行过渡；暂停、恢复、拖动进度及音频焦点变化不执行过渡。
   - 过渡期间连续收到上一首或下一首指令时采用最后一次指令生效：不中途反复切换媒体项，持续淡出当前声音，静音后只切到最后请求的目标曲目，再执行一次淡入。
   - 过渡期间发生暂停、音频焦点丢失或私密音频输出断开时，立即取消待切目标，恢复播放器正常音量，并暂停在已实际切换成功的曲目；恢复后从该曲目继续。
2. **音频焦点**：交由 ExoPlayer 自动管理；短暂焦点丢失时暂停并在焦点恢复后自动继续，允许系统在导航播报等场景自动降低音量；永久丢失后暂停且不自动继续。
3. **音频输出断开**：有线耳机、蓝牙耳机或其他私密输出设备断开时立即暂停；设备重新连接后不自动播放。
4. **后台播放服务**：播放器与 MediaSession 托管在 MediaLibraryService 中；应用任务被划走时，正在播放则继续，未播放则允许服务停止。
5. **播放恢复**：持久化队列、当前曲目、播放位置、播放模式及随机模式的稳定序列；重新打开应用只恢复界面状态，不自动播放，用户发出播放指令后从断点继续。
6. **播放历史**：每次切入一首曲目形成一个播放实例；暂停、恢复和进程恢复延续同一实例，切换离开后再次进入才创建新实例。实例的实际播放达到 `min(30 秒, 曲目时长的 50%)` 后累计次数只增加一次；实际播放时长只累计播放器处于真实播放状态的时间，暂停和缓冲不计，Seek 跳过的区间不计，重复播放同一片段照常累计。同一曲目只保留一条记录，并更新最后播放时间与累计播放次数。
7. **播放列表重复项**：同一播放列表内不允许重复曲目；重复添加时跳过，并反馈实际新增与跳过数量。
8. **歌词来源与兜底**：先在同目录同名外部 `.lrc`、内嵌 SYLT、内嵌 USLT 中选择带时间戳的来源，再按该顺序确定优先级；不接入在线歌词服务。仅当所有来源均未产出带时间戳的数据时，外部 `.lrc` 有文本则展示其原始文本，否则展示原始内嵌文本；没有任何原始文本则展示 `lyrics_not_found` 资源字符串。所有静态兜底均将三行同步歌词展示值清空为空字符串，明确表示同步不可用并避免 UI 崩溃。
   - API 29+ 未取得 SAF 目录授权时，同目录外部 `.lrc` 仅通过 MediaStore 文件索引尽力读取；未被索引或不可访问时继续按内嵌 SYLT、USLT 与无歌词兜底处理，首版不新增目录授权流程。
9. **歌词解析容错**：支持 UTF-8、带 BOM 的 UTF-16，并以 GB18030 作为最终回退；支持多时间标签与 `[offset:]`，忽略无法解析的行。
10. **歌词交互**：当前行平滑居中；用户手动滚动时暂停自动居中并显示“回到当前行”，停止操作 5 秒后自动恢复；点击带时间戳的歌词行跳转播放。
