# 性能与发布验收盘问 10

状态：已搁置（2026-07-28）

本组容量、性能、功耗、体积与长测指标保留供后续阶段重新评审，当前首版不实现相关专项优化，也不将以下推荐值作为发布阻断条件。

1. **媒体库容量按多少验收？**

   推荐：界面不设置用户可见硬上限；性能数据集包含 `50,000` 首曲目，活动播放队列包含 `10,000` 首曲目。

2. **扫描性能目标是多少？**

   推荐：Pixel 6 级别实体设备的 Release 构建中，`50,000` 首完整同步 P95 不超过 `15 秒`，`1,000` 项增删改的增量同步 P95 不超过 `2 秒`，扫描全程不阻塞主线程。

3. **启动性能目标是多少？**

   推荐：相同参考设备上，冷启动到首帧 P95 不超过 `1.5 秒`，温启动 P95 不超过 `700 ms`；使用 Macrobenchmark 测量，并生成 Baseline Profile。

4. **滚动与动画流畅度按什么标准验收？**

   推荐：60 Hz 设备上歌曲列表、歌词与队列滚动、Aero 背景同时运行时，帧时长 P95 不超过 `24 ms`，Jank 比例不超过 `5%`。

5. **内存预算是多少？**

   推荐：`50,000` 首媒体库、全屏播放器和动态 Aero 同时运行时进程 PSS 不超过 `300 MB`；后台播放且界面不可见时不超过 `120 MB`，连续切换 `500` 首后无持续增长。

6. **Aero 的功耗预算是多少？**

   推荐：固定亮度、固定音量下进行 `30 分钟` 对比测试，流体网格相对纯色静态模式的额外能耗不超过 `15%`；息屏和后台时 Canvas 帧调度必须为零。

7. **安装包体积目标是多少？**

   推荐：R8 和资源压缩后的 Release universal APK 不超过 `50 MiB`，AAB 的常见设备预估下载体积不超过 `30 MiB`，不为未使用架构打包原生库。

8. **发布设备矩阵覆盖哪些环境？**

   推荐：至少覆盖 API 26 的 `720p/2 GB` 手机、API 33 Pixel 6、API 36 手势导航手机、`1280×800` 平板、折叠屏展开态及 ChromeOS 可缩放窗口。

9. **稳定性长测标准是什么？**

   推荐：Release 构建连续本地播放 `2 小时`，执行 `1,000` 次切歌或 Seek、`200` 次页面切换与窗口变化，期间零崩溃、零 ANR、零播放服务意外终止，结束后内存回落到预算内。
