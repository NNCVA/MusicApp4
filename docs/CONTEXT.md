# MusicApp 领域词汇

本文统一 MusicApp 本地音乐播放领域中的核心业务用语，避免产品描述、界面文案与代码模型表达同一概念时产生歧义。

## 音乐资料库

**媒体库**：
应用通过 Android MediaStore 发现并纳入管理的本地音频集合；用户配置的路径只决定集合中的包含项与排除项。
_避免使用_：扫描结果、全盘文件、歌曲数据库

**曲目**：
媒体库中符合准入规则并由应用管理的单个本地音频资源；只有当前可用的曲目才能加入播放队列。
_避免使用_：文件、媒体项、歌

**曲目标识**：
由存储卷与该卷中的媒体编号共同组成的曲目身份；同一编号位于不同卷时属于不同曲目。
_避免使用_：文件路径、媒体编号

**暂时不可用曲目**：
因存储卷卸载、权限丢失或媒体库查询失败而暂时无法播放，但仍保留业务关联的曲目。
_避免使用_：缺失曲目、已删除曲目

**缺失曲目**：
已挂载存储卷完成一次成功的完整同步后，仍无法从设备媒体库发现的原曲目；该曲目及其业务关联不再保留。
_避免使用_：暂时不可用曲目、离线曲目

**路径规则**：
用户为媒体库配置的目录级包含或排除条件，用于限定曲目的发现范围。
_避免使用_：扫描路径、文件夹黑名单、过滤器

**扫描模式**：
决定从所有目录或仅从指定包含目录发现曲目的互斥状态；排除路径规则在两种状态下均优先。
_避免使用_：路径规则、扫描范围开关

**隐藏曲目**：
用户明确要求不在媒体库中展示的曲目；其物理音频文件仍保留在设备中。
_避免使用_：删除曲目、移除文件

**专辑**：
由设备媒体库判定属于同一发行集合的曲目组；名称相同但媒体库身份不同的集合仍视为不同专辑。
_避免使用_：同名曲目组、文件夹

**艺术家**：
由设备媒体库判定属于同一创作者标识的曲目组；包含合作说明的完整标签不再拆分为多个艺术家。
_避免使用_：歌手字符串、专辑艺术家

## 播放

**播放上下文**：
用户直接选择曲目时所在的已排序、已筛选曲目集合，用于建立新的播放队列。
_避免使用_：当前页面、歌曲来源

**播放队列**：
当前播放会话中已确定播放次序的曲目集合。
_避免使用_：播放列表、歌曲列表

**队列项**：
曲目在播放队列中的一次独立出现；同一曲目可以作为不同队列项重复出现。
_避免使用_：曲目标识、播放列表条目

**原始队列**：
按用户建队及后续追加顺序保存的队列项序列，是退出随机播放后恢复顺序的依据。
_避免使用_：当前播放顺序、播放列表

**稳定随机序列**：
随机播放一轮内保持不变的队列项顺序；进入下一轮后重新生成。
_避免使用_：原始队列、临时排序

**播放列表**：
用户创建并长期保存的非重复曲目集合。
_避免使用_：播放队列、收藏夹

**播放历史**：
达到有效播放条件的曲目所形成的最近播放记录。
_避免使用_：播放队列、最近添加

**播放实例**：
一次进入曲目后持续到离开该曲目的播放计时单位；暂停、恢复和进程恢复延续同一实例。
_避免使用_：播放历史、播放会话

**播放快照**：
用于恢复当前队列、曲目、位置、播放模式和播放实例计时状态的持久化断点。
_避免使用_：自动播放、播放历史

**播放模式**：
决定曲目自然结束后如何选择后续曲目的互斥状态；仅包含列表循环、单曲循环和随机播放。
_避免使用_：循环开关、随机开关、循环关闭

## 歌词

**同步歌词**：
包含可关联播放进度的时间戳、能够随播放位置切换当前行的歌词。
_避免使用_：动态歌词、滚动歌词

**静态歌词**：
没有可用时间戳、只能作为完整原始文本展示的歌词。
_避免使用_：无歌词、同步歌词
