# 系统媒体集成设计审阅 08

状态：已接受（2026-07-28）

## 已确认

- 通知栏、锁屏和系统媒体面板提供“上一首／播放暂停／下一首”三个主操作，并展示封面、标题与艺术家；快进快退、随机和循环仅在应用内提供。
- 耳机和蓝牙按键采用 MediaSession 默认命令映射，不自行解释单双击或长按；播放、暂停、上一首、下一首和 Seek 按设备命令执行。
- 播放中与暂停中的通知均允许用户划除；划除时立即停止播放、保存播放快照、清空 Player 运行时队列并停止 MediaLibraryService，持久化队列继续保留。
- 启用 Media3 Playback Resumption；进程结束或设备重启后系统可显示最后曲目的继续播放卡片，只有用户操作后才恢复队列与位置。
- MediaLibraryService 保持导出以服务系统媒体控制，但只接受本应用和 Media3 判定可信的系统控制器；其他组件除启动 Activity 外均不导出，通知 PendingIntent 统一不可变。
