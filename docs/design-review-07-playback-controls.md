# 播放控制设计审阅 07

状态：已接受（2026-07-28）

1. **播放启动反馈**：用户点击曲目后立即更新当前曲目信息并进入准备状态；准备超过 `300 ms` 才显示缓冲指示，避免本地文件快速启动时闪烁，播放失败则恢复可操作状态。
2. **快进快退**：每次快退或快进 `10 秒`，结果限制在 `0..duration`；不支持长按连续触发，锁屏、蓝牙与通知仍遵循外部控制器发送的命令。
3. **上一首语义**：无论当前曲目已播放多久，点击“上一首”都直接尝试切换到队列上一首，不先回到本曲开头；位于队首时，列表循环模式跳到队尾，其他循环状态保持队首，手动上一首不受单曲循环限制。
4. **坏文件处理**：单曲准备或解码失败时标记本次播放不可用、显示曲名与简短原因并自动尝试下一首；连续失败遍历一轮仍无可播放曲目时停止，禁止无限循环重试。
5. **播放快照**：队列、曲目、位置、随机和循环状态在队列变化、切歌、Seek、暂停及服务销毁时写入 Room；播放中每 `5 秒` 更新位置，已播至结尾的曲目恢复时从下一首或队首开始。
