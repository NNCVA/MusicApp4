# 自适应界面设计审阅 03

状态：已接受（2026-07-28）

## 已确认

- 首版适配手机、平板、折叠屏及 ChromeOS 可缩放窗口。
- 首版不制作 TV、Android Auto 或 XR 专用界面，但保留系统 MediaSession 控制能力。
- 窗口宽度 `<600 dp` 使用模态抽屉，`600–839 dp` 使用 Navigation Rail，`≥840 dp` 使用常驻展开侧栏；尺寸变化时保留当前页面与返回栈。
- 八个一级入口分别维护可保存返回栈；重复选择当前入口返回该入口根页；在非“单曲”根页按返回先切回“单曲”，再按返回退出。
- 手机模态抽屉宽度为当前窗口的 `50%`；Navigation Rail 保持标准窄栏，展开窗口的常驻侧栏使用固定宽度。
- 点击或上滑迷你播放器进入独立全屏播放器路由；返回或下滑关闭，不实现跟手连续缩放。
- 全屏播放器页面顺序为“封面／歌词／队列”；首次打开显示封面，本次进程内恢复上次页面，切歌不重置，进程重启后回到封面。
- 手势优先级为歌词或队列纵向滚动、子页横向翻页、全屏纵向关闭；列表到顶部后继续下拉时移交父视图关闭，列表底部继续上拉只做阻尼回弹。
- Aero 背景、封面和列表可绘制到系统栏后方；按钮、文字与首尾列表项按安全区避让，系统栏图标明暗跟随主题。
- 单曲、历史、文件夹和队列保持单列列表；专辑、艺术家和播放列表使用最小卡片宽度 `160 dp` 的自适应网格；设置与关于内容最大宽度为 `720 dp` 并居中。
- 使用稳定的 `MusicDimensions`、`MusicShapes`、`MusicTypography` 主题令牌按紧凑、中等、展开窗口提供统一视觉规格；页面不直接写圆角、间距或字号，不升级实验版 Compose Styles API。
- 艺术家文本固定一行并在溢出时省略，标题最多两行；卡片和列表项使用设计令牌规定的固定高度，不随文字内容增高。
- 全屏播放详情使用圆形专辑封面，其他所有位置统一使用圆角矩形封面。
- 完整尊重系统字体缩放且不限制 `fontScale`；文字超出固定组件高度时按既定行数省略。
- 歌曲类列表项与迷你播放器使用相同的 `80 dp` 固定高度。
- 网格卡片使用正方形封面加 `64 dp` 固定信息区；封面及卡片圆角在紧凑窗口为 `16 dp`，中等及展开窗口为 `20 dp`。
- 紧凑、中等、展开窗口的页面水平边距分别为 `16/24/32 dp`，卡片间距分别为 `12/16/20 dp`；组件内部尺寸遵循 `4 dp` 基准网格。
- 曲目标题与艺术家字号相差 `4 sp`：紧凑窗口分别为 `16/20 sp` 与 `12/16 sp`，中等及展开窗口分别为 `18/22 sp` 与 `14/18 sp`；标题使用 `onSurface`，艺术家使用 `onSurfaceVariant`，不通过透明度弱化颜色。
- 颜色来源可选 Material You 动态取色或预设主题，明暗模式独立提供跟随系统、浅色、深色；Android 12 以下的动态取色回退默认预设，切换时不重建 Activity。
