## W5-01：外部 LRC 纯解析器

状态：`TODO`

### 目标

先于歌词 UI 交付不依赖 Android 类型的 LRC 解码与时间标签解析器。

### 范围与文件边界

- `app/src/main/java/**/core/lyrics/lrc/`：编码探测、标签解析、offset 应用和结果模型。

### 完成条件

- 同一输入得到稳定排序结果，单行错误不丢弃其他有效歌词，解析失败有明确类型。
