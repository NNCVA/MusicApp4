状态：已实现并完成目标门禁与 Pixel 8 验收（2026-08-09）

## 2. 已确认决策

- 艺术家仍按 MediaStore Artist ID 分组；合作标签保留完整内容，不拆分为多个艺术家。
- 艺术家集合页固定按名称升序，不提供集合页排序；进入艺术家详情页后沿用详情页既有排序规则。
- 右侧索引固定提供完整 `0/A–Z/#` 范围，支持点击或沿索引拖动定位；没有对应分组的空标签只用于定位，不承担筛选。
- 艺术家头像按该艺术家曲目的 `TrackId` 稳定升序选择首张可用内嵌封面；没有可用封面时使用艺术家占位图。
- Mini Player 与详情页视觉不在本次范围内；圆形封面例外仅适用于 Full Player 与艺术家集合头像。

## 3. 范围边界

范围内：艺术家集合页标题、单列行、头像与辅助文本、完整索引交互、无障碍语义，以及手机、平板和可缩放窗口下的自适应呈现；实现使用现有设计令牌，不写像素级位置承诺。

范围外：Mini Player、Full Player 和详情页视觉；专辑与播放列表集合页（继续使用网格）；MediaStore Artist ID 分组语义、合作标签拆分、在线封面或新增数据模型；不新增 ADR。

## 4. 数据与封面规则

- 集合项的数据源为 Room 派生的艺术家分组，艺术家身份和合作标签规则保持不变。
- 集合排序只使用艺术家名称升序，页面不保存或恢复集合页排序选择；详情页不改变既有排序记忆。
- 头像选择在稳定的 `TrackId` 顺序上取首张可用内嵌封面；解析失败、缺失或无封面统一回退艺术家占位图。
- 集合项不展示专辑数，曲目数使用短辅助文本；截图中的名称和数量不写入测试夹具作为固定业务数据。

## 5. UI、无障碍与适配要求

- 标题保持紧凑层级；集合项始终为单列圆形头像行，显示艺术家名和短曲目数，窗口变宽时仍保持单列布局。
- 完整 `0/A–Z/#` 索引位于列表侧边；每个标签可点击，连续拖动沿索引定位并更新当前分组，空标签仍可定位到邻近分组且不改变筛选结果。
- 行、索引标签和占位头像均符合项目最小触控目标规范并提供资源化语义描述；TalkBack 可读出艺术家名、曲目数、当前分组和索引动作，拖动结束后播报定位结果。
- 尊重系统字体缩放、明暗主题和中英文资源；长名称省略但不遮挡索引或操作目标，加载、空态和错误态沿用共享组件。
- 紧凑、中等、展开窗口均保持单列集合项；水平留白、行高、间距和头像尺寸从设计令牌读取，Insets 与底部 Mini 空间由应用壳层统一处理。

## 6. 验证顺序

1. 按 [`../verification.md`](../verification.md) 的分层规则执行受影响的纯逻辑测试、Lint、Debug 构建和设备侧测试，并分别记录真实结果。
2. 门禁完成后在 Pixel 8 进行截图和 UI 树采集，再按清单目视比对；截图比对用于视觉验收，不替代自动门禁。

## 7. Pixel 8 验收清单

- 标题层级紧凑，集合页无名称排序入口、无专辑数。
- 所有集合项为单列圆形头像行，名称与短曲目数层级清晰；无封面项显示艺术家占位图。
- 右侧完整 `0/A–Z/#` 可见；点击任一标签、沿索引拖动和松手后的定位结果与 UI 树语义一致，空标签只定位不筛选。
- 长名称、系统字体放大、Light/Dark 和中英文下无裁切、重叠或不可操作目标；索引和列表行均能被 TalkBack 识别。
- 截图与 UI 树共同确认单列、圆形头像、固定名称升序和短曲目数；不把参考图中的具体曲目、数字或封面当作业务保证。

## 8. 验收结果

当前没有新增领域决策。JVM、Lint 与 Debug APK 门禁均已通过；Pixel 8 API 34 模拟器真实执行 Android Runtime 集成测试 `31/31` 通过。设备截图与 UI 树确认单列圆形头像、短曲目数、完整 `0/A–Z/#` 语义节点及 Mini Player 共存布局；点击 `F` 定位到方大同、连续拖动到 `C` 定位到 Charlie Puth/Selena Gomez，索引交互通过。
